ORCHID PURCHASE MANAGER PROFESSIONAL 4.9.31

INSTALL ON MAC
- Close the previous Orchid Purchase Manager version.
- Move “Orchid Purchase Manager Professional 4.9.31.app” to Applications.
- Open it normally. Your Orchid Purchase Manager 2 Data folder remains separate and is not replaced.

TEST 2 PURCHASE-ORDER CHECK
1. Open the existing Test 2 event.
2. Open Purchase Orders.
3. Select “Prepare & Assign PO Numbers.”
4. Confirm the PO-number assignment window opens in front of the app.
5. Enter one PO number for every vendor shown, including internal/manual receiving vendors.
6. Select “Save & Generate Purchase Orders.”
7. Confirm Orchid shows an explicit Purchase Orders Created confirmation and lists the PDFs on the Purchase Orders page.
8. Open the folder and inspect the vendor POs and outsourced decoration report before using them.

No report is considered generated merely because reconciliation finishes. Orchid verifies the final report folder, released PDF count, and protected release manifest before showing success.

IN-HOUSE RECEIVING & DECORATION REPORT
Each vendor section shows its saved PO number in the heading, for example
“Berne Apparel - PO # Berne Line 2026.” Internal routing labels such as
“MANUAL / NON-INCLUDED” no longer appear in place of that PO number. The
Received checkbox is the first column, immediately before Product #, so it
remains practical even when Notes / Instructions is wide.

The vendor header now contains only the vendor and PO number. Each vendor
section ends with a full-width, left-aligned footer such as “VENDOR TOTAL: 2,”
matching the cleaner Non-Included Items report.

The header now uses one clear job-name line, such as “Test 2,” directly below
the report name. The redundant “Internal Receiving & Decoration Worksheet”
line has been removed.

NON-INCLUDED ITEMS
The redundant manual-order instruction line is removed. The job name is larger
and each vendor total stays together on the left, for example “VENDOR TOTAL: 2.”

OUTSOURCED JOB REPORTS
Use the Logo page tabs to set up Embroidery and Screen Printing separately. The selected tab uses a dark, high-contrast department color with white lettering: purple for Embroidery and blue for Screen Printing. Each tab displays only the artwork colors used by that department. When reports are generated, Orchid creates one outsourced embroidery job report and one outsourced screen-printing job report when those departments have work.

Each department-specific report places its color-by-color piece summary on the logo cover page. It lists the thread or ink colors used in that department, the pieces for each color, and the final embroidered or screen-printed piece total before the artwork and garment quantities.

OUTSOURCED REPORT COVER
The first page is a concise, one-page production overview: each decoration location has its own piece total, and the department's thread/ink color totals and final piece total appear beside it. This prevents Left Chest and Left Sleeve from being read as if every garment receives both locations. Artwork color names are centered above their matching artwork. On multi-color jobs, Orchid tightens the artwork grid and uses a two-column color summary so the cover stays together and garment quantities always begin on page 2. Uploaded artwork is saved as a cleaned transparent PNG for the report; the original file is never changed.

The two PIECES headings in the thread/ink color summary remain on one clean
line. The width was rebalanced within the existing table, so this polish does
not consume extra vertical space or move the artwork and production details
off the one-page cover.

CURRENT EVENT
The redundant Import Orders icon above the current job name and logo has been
removed. Import, replace, and add-order actions remain available in their
normal buttons below the event details.

VENDOR PURCHASE ORDERS
The Quantity heading has dedicated column width and remains on one line in
every vendor purchase order. Employee / Order remains available for its full
customer, employee, and order trace.
